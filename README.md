# 🚀 [NetWorking System]

Uma aplicação web moderna desenvolvida com **React**, **TypeScript** e **Vite**, focada em performance, tipagem estática segura e uma experiência de desenvolvimento extremamente rápida.

---

## 🛠️ Tecnologias e Ferramentas

O projeto foi inicializado utilizando a estrutura oficial do Vite com os seguintes pilares:

* **[React](https://react.dev/):** Biblioteca para construção de interfaces de usuário baseadas em componentes.
* **[TypeScript](https://www.typescriptlang.org/):** Supersuposto JavaScript que adiciona tipagem estática ao código.
* **[Vite](https://vite.dev/):** Build tool ultra-rápida com suporte a HMR (Hot Module Replacement).
* **React Compiler:** Habilitado para otimização automática de re-renderizações (pode impactar levemente o tempo de build/dev em troca de melhor performance em runtime).
* **Plugins de Transpilação:** * `@vitejs/plugin-react` (via Babel/Oxc) ou `@vitejs/plugin-react-swc` (via SWC) para Fast Refresh.
